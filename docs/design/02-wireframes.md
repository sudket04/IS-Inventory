## 0. ข้อตกลงร่วมของทุกหน้า (Global Conventions)

### 0.1 Grid & Breakpoint

| Breakpoint | ความกว้าง | พฤติกรรม |

| **Tablet** | 768 – 1279px | Sidebar ยุบเป็นไอคอน · ตารางเลื่อนแนวนอนได้ · ฟอร์ม 2 คอลัมน์ |

### 0.3 รูปแบบรหัสทรัพย์สิน (Asset Tag Generation)

ระบบสร้างรหัสอัตโนมัติในรูปแบบ **`[PREFIX]-[YYYY]-[NNNN]`**
โดยฟอร์มจะแสดงรหัสที่จะได้รับล่วงหน้าในช่องแบบอ่านอย่างเดียว พร้อมไอคอน 🔒

| ประเภททรัพย์สิน | Prefix | ตัวอย่าง |
|---|---|---|
| Server | `SRV` | `SRV-2026-0001` |
| Network Device | `NET` | `NET-2026-0042` |
| Software License | `SFT` | `SFT-2026-0007` |
| Computer (PC/Notebook) | `PC` | `PC-2026-0315` |
| Storage & Power | `STG` | `STG-2026-0011` |
| Peripheral | `PER` | `PER-2026-0088` |

**กติกา:** เลขลำดับแยกนับตามประเภทและปี · รีเซ็ตเป็น `0001` ทุกต้นปี ·
รหัสที่ออกไปแล้วจะไม่ถูกนำกลับมาใช้ซ้ำแม้รายการนั้นถูกลบ (ป้องกันความสับสนในการตรวจสอบย้อนหลัง) ·
ขณะนำเข้าจาก Excel ระบบยอมรับ Asset Tag เดิมจากไฟล์ได้ เพื่อรักษารหัสที่องค์กรใช้อยู่

### 3.1 โครงสร้าง Stacked Cell (7 คอลัมน์ · 11 ข้อมูล)

| # | คอลัมน์ | บรรทัดบน (เด่น) | บรรทัดล่าง (สีจาง ขนาดเล็กกว่า) |

| 1 | Asset Tag | **`SRV-2026-0031`** | Category |
| 2 | Name | **ยี่ห้อ + รุ่น** | `SN: xxxxx` |
| 3 | Status | 🟢 **Badge** | — |
| 4 | Network | **IP Address** | Hostname |
| 5 | Location | **สถานที่ / Rack** | ผู้ดูแล |
| 6 | Warranty | **วันหมดประกัน** | นับถอยหลังพร้อมสี |
| 7 | Financial | **ราคา** | วันที่ซื้อ |

> ทั้ง 11 ข้อมูลที่ร้องขอปรากฏครบ โดย**ไม่ต้องเลื่อนแนวนอน**บนจอ 1440px ขึ้นไป
> ผู้ใช้ปรับได้เองผ่านปุ่ม `( Columns )` และระบบจดจำค่าที่เลือกไว้

### 3.2 หมายเหตุการออกแบบ

| ประเด็น | เหตุผล |
|---|---|
| **แท็บแยกประเภทพร้อมจำนวนในวงเล็บ** | ผู้ใช้เห็นสัดส่วนข้อมูลทันทีโดยไม่ต้องกรอง |
| **Filter Chips แสดงเงื่อนไขที่ใช้อยู่** | ปัญหาคลาสสิกคือผู้ใช้ลืมว่ากรองอะไรไว้ แล้วคิดว่าข้อมูลหาย |
| แถบ Bulk Action โผล่เมื่อเลือกรายการเท่านั้น | ไม่รกหน้าจอในสภาวะปกติ |

### หมายเหตุการออกแบบ

| ประเด็น | เหตุผล |
|---|---|
| **แยก Error กับ Warning ให้ชัดเจน** | Error = บันทึกไม่ได้ · Warning = บันทึกได้แต่ควรรู้ไว้ ผู้ใช้จึงตัดสินใจได้ถูก |
| ระบุ**เลขแถวในไฟล์ Excel** | ผู้ใช้กลับไปแก้ในไฟล์ต้นทางได้ทันทีโดยไม่ต้องไล่หา |
| ปุ่มดาวน์โหลดรายงานข้อผิดพลาดเป็น Excel | แก้ในไฟล์เดิมได้เลย ไม่ต้องจดใส่กระดาษ |
| ปุ่มยืนยันระบุจำนวนชัดเจน "Import 1,879 valid rows" | ผู้ใช้รู้แน่ชัดว่ากำลังจะทำอะไร ไม่ใช่ปุ่ม "OK" ที่คลุมเครือ |
| กล่องยืนยันบอกว่าจะถูกบันทึกลง Audit Log | สร้างความรับผิดชอบและความโปร่งใส |

### หมายเหตุการออกแบบ

| ประเด็น | เหตุผล |
|---|---|
| **แถบข้อความ 🔒 Append-only อยู่บนสุด** | สื่อสารคุณสมบัติด้าน Compliance ให้ผู้ตรวจสอบเห็นทันที |

| เก็บและแสดง IP Address + User Agent | จำเป็นต่อการสืบสวนกรณีเกิดเหตุผิดปกติ |
| ตารางเปรียบเทียบเฉพาะฟิลด์ที่เปลี่ยน | ไม่แสดงฟิลด์ที่ไม่เปลี่ยน เพื่อให้เห็นประเด็นทันที |
