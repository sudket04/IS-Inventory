## 1. ปรัชญาการออกแบบ (Design Principles)

| หลักการ | ความหมายในระบบนี้ |
|---|---|
| **1. ข้อมูลต้องอ่านง่ายก่อนสวยงาม** | ระบบนี้คือเครื่องมือทำงาน ไม่ใช่งานโฆษณา ความคมชัดของตัวอักษรและความถูกต้องของข้อมูลสำคัญกว่าลูกเล่น |
| **2. สีต้องมีความหมายเดียวเสมอ** | สีแดงหมายถึงอันตรายหรือหมดอายุ**เท่านั้น** ห้ามนำไปใช้ตกแต่ง มิฉะนั้นผู้ใช้จะเลิกเชื่อถือสัญญาณเตือน |
| **3. ไม่สื่อความหมายด้วยสีเพียงอย่างเดียว** | ทุก Badge สถานะต้องมีทั้งสี จุดสัญลักษณ์ และข้อความกำกับ รองรับผู้ใช้ตาบอดสี (WCAG AA) |
| **4. ความหนาแน่นของข้อมูลเป็นคุณสมบัติ ไม่ใช่ข้อบกพร่อง** | ผู้ใช้หลักเป็นทีม IT ที่ต้องกวาดสายตาดูข้อมูลจำนวนมาก จึงใช้ Font ขนาดฐาน 14px ไม่ใช่ 16px แบบเว็บทั่วไป |
| **5. Dark Mode คือพลเมืองชั้นหนึ่ง** | ไม่ใช่การกลับสีขาว-ดำแบบง่ายๆ แต่ปรับค่าความสว่างของทุก Token แยกต่างหาก |

## 3. Semantic Tokens (ตัวแปรที่โค้ดเรียกใช้จริง)

**หลักการสำคัญ:** โค้ดใน Component ต้องเรียกใช้ **Semantic Token เท่านั้น** ห้ามใส่ค่าสีดิบ
เช่น `slate-200` ลงไปตรงๆ มิฉะนั้น Dark Mode จะพังเมื่อมีการแก้ไขในอนาคต

| Token | Light | Dark | ใช้กับ |
|---|---|---|---|
| `--bg-canvas` | `#F8FAFC` | `#020617` | พื้นหลังของหน้าทั้งหมด |
| `--bg-surface` | `#FFFFFF` | `#0F172A` | การ์ด · ตาราง · Modal |
| `--bg-subtle` | `#F1F5F9` | `#1E293B` | หัวตาราง · แถวที่ถูก Hover |
| `--bg-inset` | `#F1F5F9` | `#020617` | ช่องกรอกข้อมูล · บล็อกโค้ด |
| `--border-default` | `#E2E8F0` | `#1E293B` | เส้นขอบทั่วไป |
| `--border-strong` | `#CBD5E1` | `#334155` | เส้นขอบช่องกรอก · เส้นคั่น |
| `--text-primary` | `#0F172A` | `#F1F5F9` | หัวข้อ · ข้อมูลหลัก |
| `--text-secondary` | `#475569` | `#94A3B8` | ป้ายกำกับ · บรรทัดรองใน Stacked Cell |
| `--text-tertiary` | `#94A3B8` | `#64748B` | ข้อความช่วยเหลือ · Placeholder |
| `--accent` | `#4F46E5` | `#6366F1` | ปุ่มหลัก · แท็บที่เลือก |
| `--accent-text` | `#4F46E5` | `#818CF8` | ลิงก์ (ในโหมดมืดต้องสว่างกว่าพื้นปุ่ม) |
| `--focus-ring` | `#6366F1` | `#818CF8` | วงแหวนตอนโฟกัสด้วยคีย์บอร์ด |

### 3.1 การประกาศตัวแปรใน CSS

```css
:root {
  --bg-canvas:       #F8FAFC;
  --bg-surface:      #FFFFFF;
  --bg-subtle:       #F1F5F9;
  --bg-inset:        #F1F5F9;
  --border-default:  #E2E8F0;
  --border-strong:   #CBD5E1;
  --text-primary:    #0F172A;
  --text-secondary:  #475569;
  --text-tertiary:   #94A3B8;
  --accent:          #4F46E5;
  --accent-hover:    #4338CA;
  --accent-text:     #4F46E5;
  --focus-ring:      #6366F1;
}

:root.dark {
  --bg-canvas:       #020617;
  --bg-surface:      #0F172A;
  --bg-subtle:       #1E293B;
  --bg-inset:        #020617;
  --border-default:  #1E293B;
  --border-strong:   #334155;
  --text-primary:    #F1F5F9;
  --text-secondary:  #94A3B8;
  --text-tertiary:   #64748B;
  --accent:          #6366F1;
  --accent-hover:    #818CF8;
  --accent-text:     #818CF8;
  --focus-ring:      #818CF8;
}
```

> **หมายเหตุการติดตั้ง:** ใช้ Class `.dark` บน `<html>` ไม่ใช่ `prefers-color-scheme` เพียงอย่างเดียว
> เพราะผู้ใช้ต้องสลับธีมเองได้ และค่าที่เลือกต้องถูกจดจำไว้ใน `localStorage`
> พร้อมสคริปต์ขนาดเล็กใน `<head>` เพื่อกำหนดธีมก่อนหน้าเว็บจะแสดงผล — ป้องกันอาการจอขาววาบ

## 4. Typography

### 4.1 ฟอนต์ที่ใช้

| บทบาท | ฟอนต์ | ใช้กับ |
|---|---|---|
| **UI ทั่วไป** | Inter | ข้อความทั้งหมด หัวข้อ ปุ่ม ป้ายกำกับ |
| **ข้อมูลเชิงเทคนิค** | JetBrains Mono | Asset Tag · Serial No. · IP · MAC · License Key · รหัสอ้างอิง |

> ⚠️ **ข้อกำหนดสำหรับ On-Premise:** ต้อง **Self-host ฟอนต์ทั้งสอง** ในโปรเจกต์
> (ผ่าน `next/font/local`) ห้ามโหลดจาก Google Fonts CDN เพราะเซิร์ฟเวอร์ภายในองค์กร
> อาจไม่มีทางออกอินเทอร์เน็ต ซึ่งจะทำให้ข้อความแสดงผลผิดพลาดทั้งระบบ

**เหตุผลที่เลือก JetBrains Mono สำหรับข้อมูลเทคนิค:** ฟอนต์นี้แยก `0` กับ `O` และ `1` กับ `l`
ได้ชัดเจน ซึ่งเป็นเรื่องคอขาดบาดตายสำหรับการอ่าน Serial Number และ IP Address
นอกจากนี้ความกว้างตัวอักษรคงที่ทำให้ตัวเลขในตารางเรียงตรงกันเป็นคอลัมน์

### 4.2 Type Scale

| ชื่อ | ขนาด | ระยะบรรทัด | น้ำหนัก | ใช้กับ |
|---|---|---|---|---|
| `display` | 30px | 36px | 700 | ตัวเลขใหญ่บนการ์ด Dashboard |
| `h1` | 24px | 32px | 600 | ชื่อหน้า |
| `h2` | 20px | 28px | 600 | ชื่อส่วนย่อย · หัวข้อ Modal |
| `h3` | 16px | 24px | 600 | หัวข้อการ์ด |
| `body-lg` | 16px | 24px | 400 | ข้อความนำ |
| **`body`** | **14px** | **20px** | **400** | ⭐ **ขนาดฐานของทั้งระบบ** |
| `body-sm` | 13px | 18px | 400 | บรรทัดรองใน Stacked Cell |
| `caption` | 12px | 16px | 500 | หัวตาราง (ตัวพิมพ์ใหญ่) · ป้ายกำกับ |
| `mono` | 13px | 20px | 450 | ข้อมูลเชิงเทคนิค |
| `mono-sm` | 12px | 16px | 450 | ข้อมูลเทคนิคในบรรทัดรอง |

> **ข้อยกเว้นสำคัญ:** ช่องกรอกข้อมูล (`<input>`, `<select>`, `<textarea>`) ต้องมีขนาด
> **16px บนหน้าจอมือถือ** เพราะ iOS Safari จะซูมหน้าจอเข้าอัตโนมัติหากฟอนต์เล็กกว่านั้น
> ซึ่งทำให้เลย์เอาต์พังทันที

### 4.3 กติกาการจัดวางตัวเลข

| ประเภทข้อมูล | การจัดวาง | รูปแบบ |
|---|---|---|
| ราคา / จำนวนเงิน | ชิดขวา | `฿ 285,000` ใช้ `tabular-nums` |
| จำนวนนับ | ชิดขวา | `2,347` |
| วันที่ | ชิดซ้าย | `22 Oct 2026` (เดือนเป็นตัวอักษร ป้องกันความสับสน DD/MM กับ MM/DD) |
| วันที่+เวลา (Audit) | ชิดซ้าย | `16 Sep 2026 09:42:17` |
| IP / Serial / MAC | ชิดซ้าย | ฟอนต์ Mono |

### 5.4 Elevation (เงา)

| Token | Light Mode | Dark Mode |
|---|---|---|
| `shadow-xs` | `0 1px 2px rgba(15,23,42,.05)` | ใช้เส้นขอบ `1px #1E293B` แทน |

| `shadow-md` | `0 4px 12px rgba(15,23,42,.10)` | ใช้พื้นหลังสว่างขึ้น 1 ระดับ + เส้นขอบ |

> จึงต้องสร้างมิติด้วย **ความสว่างของพื้นผิวและเส้นขอบ** แทนการใช้เงา

## 6. Component Specification

### 6.1 Button

| Variant | พื้นหลัง | ข้อความ | เส้นขอบ | ใช้เมื่อ |
|---|---|---|---|---|
| **Primary** | `--accent` | ขาว | ไม่มี | การกระทำหลัก 1 อย่างต่อหน้า เช่น Save, New Asset |
| **Secondary** | `--bg-surface` | `--text-primary` | `--border-strong` | การกระทำรอง เช่น Export, Cancel |
| **Ghost** | โปร่งใส | `--text-secondary` | ไม่มี | ปุ่มไอคอนในตาราง · ปุ่มปิด |
| **Destructive** | `#DC2626` | ขาว | ไม่มี | ลบ · ตัดจำหน่าย (ต้องมีกล่องยืนยันเสมอ) |
| **Link** | โปร่งใส | `--accent-text` | ไม่มี | ลิงก์ในเนื้อหา |

**ขนาดและสถานะ**

| ขนาด | ความสูง | Padding | ฟอนต์ |
|---|---|---|---|
| `sm` | 32px | 12px | 13px |
| `md` (ค่าเริ่มต้น) | 36px | 16px | 14px |
| `lg` | 40px | 20px | 14px |
| `icon` | 36 × 36px | — | ไอคอน 16px |

| สถานะ | พฤติกรรม |
|---|---|
| Hover | พื้นหลังเข้มขึ้น 1 ระดับ · เปลี่ยนภายใน 150ms |
| Active | พื้นหลังเข้มขึ้น 2 ระดับ |

| Disabled | ความทึบ 50% · เคอร์เซอร์ `not-allowed` |
| Loading | ไอคอนหมุนแทนที่ข้อความ · **ล็อกความกว้างปุ่มไว้** ป้องกันหน้าจอกระตุก |

> **กฎเหล็กด้าน Accessibility:** ห้ามลบวงแหวน Focus ออกโดยเด็ดขาด
> ผู้ใช้ที่ใช้คีย์บอร์ดจะไม่รู้เลยว่าตอนนี้อยู่ตรงไหน — ใช้ `:focus-visible` เพื่อให้
> วงแหวนแสดงเฉพาะตอนใช้คีย์บอร์ด ไม่แสดงตอนคลิกเมาส์

### 6.2 Input

```
   Label (13px, 500, --text-secondary)
  ┌──────────────────────────────────────┐
  │ Placeholder or value       (36px สูง)│  ← พื้น --bg-surface
  └──────────────────────────────────────┘     ขอบ 1px --border-strong
   Helper text (12px, --text-tertiary)          radius 6px

   สถานะ Error:
  ┌──────────────────────────────────────┐
  │ Invalid value                        │  ← ขอบ 1px #DC2626
  └──────────────────────────────────────┘
   ⚠ Serial number already exists  (12px, #DC2626)
```

| สถานะ | รูปแบบ |
|---|---|
| Default | ขอบ `--border-strong` |
| Hover | ขอบเข้มขึ้น 1 ระดับ |
| **Focus** | ขอบ `--accent` + วงแหวน 2px `--focus-ring` |
| Error | ขอบ Danger + ข้อความอธิบายด้านล่าง + ไอคอน ⚠ |
| Disabled | พื้น `--bg-subtle` · ข้อความ `--text-tertiary` |
| Read-only (เช่น Asset Tag) | พื้น `--bg-subtle` · มีไอคอน 🔒 ด้านขวา |

> **กติกาข้อความ Error:** ต้องบอก**วิธีแก้** ไม่ใช่แค่บอกว่าผิด
> ❌ `"Invalid input"` → ✅ `"Serial number already exists on SRV-2026-0031"`

## 8. Motion & Interaction

| การเคลื่อนไหว | ระยะเวลา | Easing |
|---|---|---|
| Hover ของปุ่มและลิงก์ | 150ms | `ease-out` |
| เปิด/ปิด Dropdown | 150ms | `ease-out` |
| เปิด/ปิด Modal | 200ms | `ease-out` |

| Toast เข้า/ออก | 250ms | `ease-out` |

## 9. Accessibility Checklist (WCAG 2.1 Level AA)

| # | ข้อกำหนด | สถานะการออกแบบ |
|---|---|:---:|
| 1 | ความต่างของสีข้อความปกติ ≥ 4.5:1 | ✅ ตรวจแล้วทั้งสองธีม |
| 2 | ความต่างของสีข้อความใหญ่ ≥ 3:1 | ✅ |
| 3 | ความต่างของเส้นขอบและองค์ประกอบ UI ≥ 3:1 | ✅ |
| 4 | ไม่สื่อความหมายด้วยสีเพียงอย่างเดียว | ✅ ทุก Badge มีจุดสัญลักษณ์ + ข้อความ |
| 5 | วงแหวน Focus มองเห็นได้ชัดเจนทุกองค์ประกอบ | ✅ 2px + ระยะเว้น 2px |
| 6 | ใช้งานได้ด้วยคีย์บอร์ดทั้งหมด | ✅ รวมถึงตาราง Modal และ Dropdown |
| 7 | เป้าหมายการกดบนมือถือ ≥ 44 × 44px | ✅ |
| 8 | ช่องกรอกทุกช่องมี Label ที่เชื่อมโยงกัน | ✅ ไม่ใช้ Placeholder แทน Label |
| 9 | ข้อความ Error เชื่อมกับช่องด้วย `aria-describedby` | ✅ |
| 10 | รองรับ `prefers-reduced-motion` | ✅ |
| 11 | ปรับขนาดข้อความได้ถึง 200% โดยเลย์เอาต์ไม่พัง | ✅ ใช้หน่วย rem |

### 10.3 สคริปต์ป้องกันจอขาววาบตอนโหลด

```html
<!-- วางไว้ใน <head> ก่อนทุกอย่าง -->
<script>
  (function () {
    try {
      var t = localStorage.getItem('kknd-theme');
      var d = window.matchMedia('(prefers-color-scheme: dark)').matches;
      if (t === 'dark' || (!t && d)) document.documentElement.classList.add('dark');
    } catch (e) {}
  })();
</script>
```

> ปัญหาที่สคริปต์นี้แก้: หากรอให้ React โหลดเสร็จก่อนจึงค่อยใส่ธีม

> ซึ่งแสบตามากในห้อง Data Center ที่แสงน้อย
